# Azmi0505 Node.js Starter

Starter repository for a Node.js service with basic structure, test setup, and CI.

## Prerequisites

- Node.js 20+

## Setup

```bash
npm install
```

## Run

```bash
npm start
```

## Test

```bash
npm test
```

## Lint (syntax check)

```bash
npm run lint
```

## Project structure

- `src/` application source code
- `tests/` test files
- `docs/` project documentation
- `.github/workflows/` CI pipelines
